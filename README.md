# Prakashraj E — Portfolio

Cinematic black + red portfolio. Pure HTML / CSS / JS — **no build step, no dependencies.**

## Run locally
Open `index.html` in a browser (or `python3 -m http.server 5173` and visit http://localhost:5173).

## Deploy (free)
Drag this whole folder onto **Netlify Drop** (app.netlify.com/drop), or push to GitHub and enable
**GitHub Pages** (Settings -> Pages -> Deploy from branch `main` / root).

## MUST EDIT — replace these placeholder links in `index.html`
Search for each and paste your real URL:

| Search for                    | Replace with                                  |
|-------------------------------|-----------------------------------------------|
| `https://github.com/` (nav)   | your GitHub profile, e.g. github.com/yourname |
| `data-repo="JOBPORTAL"` link  | github.com/yourname/JOBPORTAL                 |
| `data-repo="NLPC"` link       | github.com/yourname/NLPC                      |
| `https://www.linkedin.com/`   | your LinkedIn profile URL                     |

## Files
- `index.html`  – all content (from your resume)
- `style.css`   – theme, layout, animations
- `main.js`     – boot sequence, embers, parallax, reveals
- `assets/prakash.png` – your photo (transparent PNG)
- `Prakashraj_E_Resume.pdf` – the Download Resume button
